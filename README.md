# Workshop Projeto Você S.A. com Roger

Página de vendas completa para o workshop de entrada do Projeto Você S.A.

## Rotas

* `/a1`: hero com o ângulo de dor e nova saída.
* `/a2`: hero com o ângulo de quebra de crença sobre risco.
* `/a3`: hero com o ângulo de resultado e quebra da objeção sobre virar trader.
* `/obrigado`: orientação segura após a inscrição.

As páginas A1, A2 e A3 compartilham estrutura, conteúdo, oferta e identidade visual. Somente a hero muda entre as três versões.

## Uso local

1. Instale as dependências com `npm install`.
2. Inicie o projeto com `npm run dev`.
3. Gere a versão de produção com `npm run build`.
4. Execute a validação completa com `npm test`.

## Informações pendentes

O projeto não inventa dados operacionais ausentes. Antes da campanha, configure o checkout oficial e confirme as datas, o canal de suporte, o eventual grupo de participantes, a política de garantia e o domínio personalizado.
